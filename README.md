# Arabic Typing Tutor

Learn to touch-type Arabic on the keyboard you already own, no Arabic keycaps needed.

**[⬇ Download the latest release](https://github.com/ST3-Studios/att/releases/latest)** (macOS and Windows, free)

![Lesson view](screenshots/lesson.png)

## Features
- 100 progressive lessons, from the home row to news, literature and master challenges
- On-screen Arabic keyboard that lights up the next key and adapts to your layout (Apple Arabic, Arabic – PC, Persian, Urdu…)
- Proper right-to-left typing with correctly joined Arabic letters
- Two-line focus view, or expand to see the whole passage
- Free Type mode, plus Race, Hangman and Sayings & Proverbs games
- Stats (accuracy, speed, streak, key accuracy, history), 22 trophies, and kid / teen / adult themes
- Interface in Arabic, English, French, German and Spanish

## Install
Download the file for your system from the [releases page](https://github.com/ST3-Studios/att/releases/latest).

See **Is it safe?** below for the one-time step to open it.

Then add an Arabic keyboard to your system:
- **macOS:** add the **Arabic – PC** input source.
- **Windows:** add **Arabic (101)**.

## Is it safe? About the "malware" warning
When you first open Arabic Typing Tutor, your Mac may say: *"Apple could not verify 'Arabic Typing Tutor' is free of malware…"*. **This is not a virus detection.** macOS shows this message for every app that isn't registered with Apple's paid developer program, and this small independent project hasn't joined it yet. Windows shows a similar "Windows protected your PC" screen.

- The app has **no ads, no tracking and no hidden software**. Its only internet connection is a check for new versions on GitHub or itch.io.
- Download it only from the official pages: **[GitHub](https://github.com/ST3-Studios/att/releases/latest)** or **[itch.io](https://shanet3.itch.io/arabic-typing-tutor-plus)**.
- **Opening it the first time on a Mac:** click **Done**, open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**, then confirm. **On Windows:** click **More info → Run anyway**. You only do this once.
